Command line

The lemmata command checks .aether files from a terminal or a script, and exits with status 1 when a step is invalid. The installer uses uv to give it its own Python, so nothing else on your system changes. Read it first if you like: install.sh, install.ps1.

macOS and Linux

curl -fsSL https://lemmata.sous.systems/install.sh | sh

Windows (PowerShell)

irm https://lemmata.sous.systems/install.ps1 | iex

Then lemmata proof.aether prints the audit. Run the installer again to upgrade; uv tool uninstall aether removes it.

Host your own copy

The app is a folder of static files with the checker inside, so any web server can host it: a department's own, GitHub Pages, or a laptop for a seminar. One file, site.json, makes it yours:

FieldWhat it sets
name, taglineWhat the app calls itself, in the page title, the welcome and the exports.
accentThe one brand colour, for light and dark. It must reach 4.5:1 contrast, or the default is kept.
registryWhere packs are searched and installed from: this public registry, your own copy of it, or none.
preinstallThe packs a first visit installs, such as your module's.

Build it from the source with LEMMATA_SITE=site.json uv run python ui/build_static.py and serve the dist/ folder. The same file builds a branded desktop app. The README has the details.
