Writing a proof

Indentation matters, as in Python: four spaces open a nested block. Everything else reads like the proofs in your notes.

Justifying a step

Append [by algebra], [by definition] or [using h1] to say why a step holds. A justification that names something out of scope is refused, so it doubles as a check on your own reasoning.

Let k, n : Int
Assume h1: n = 2 * k
Step: n = 2 * k [using h1]

Writing it as the notes do

Lecture notes say Let ε > 0 be given, Take δ = ε/3, Since …, … and By …, …. So can you: each of these means what it says, and is checked the same way as the keyword it stands for. Since A, B checks A first, then B using it.

Let ε > 0 be given
Take δ = ε / 3
Since δ > 0, 3 * δ > 0
We have 3 * δ = ε
Let x : Real
Assume h1: x > 2
Since x > 3, x^2 > 9

Citing a result by name

Write by Theorem 1.1 — or By the triangle inequality, … — and the result is found among your installed packs and your workspace's theorems, with no import line. It is used for that step alone, and the audit says which result it was; a name that could mean two results is refused rather than guessed. Typing after by lists what you can cite.

When a step fails

A failing step says what to try, in your notation: the assumption a division needs, how far apart the two sides of an equation are, that a > holds as ≥. Where one edit would mend it there is a button for it, in Context & state and in the editor's tooltip; Ctrl+Z takes it back.

Let x : Real
Assume x >= 2
Therefore x > 2

A claim checked at QED

With a Claim:, QED checks that the proof really established it — every assumption you made must be licensed by the claim's own hypotheses.

Theorem: "Goal"
Claim: forall n : Int, Even(n) => MultipleOf(n^2, 4)
Proof:
    Given n : Int
    Assume hn: Even(n)
    Obtain k : Int such that n = 2 * k from hn
    Step: n^2 = 4 * k^2
    Hence MultipleOf(n^2, 4)
QED

Induction

Theorem: "Sum of odds"
Claim: forall n : Nat, sum(k, 1, n, 2 * k - 1) = n^2
Proof:
    Base case n = 0:
        Step: sum(k, 1, 0, 2 * k - 1) = 0
        Step: = 0^2
    Inductive step:
        Fix n : Nat
        Assume ih: sum(k, 1, n, 2 * k - 1) = n^2
        Step: sum(k, 1, n + 1, 2 * k - 1) = n^2 + (2 * (n + 1) - 1)
        Step: = n^2 + 2 * n + 1
        Step: = (n + 1)^2
    Therefore forall n : Nat, sum(k, 1, n, 2 * k - 1) = n^2
QED

Several files

A proof can import another file in your workspace. The path is relative to the importing file's folder, falling back to the top of the workspace; the imported file's theorems become facts you can use.
