Quantifiers, as the notes write them

∀ ε > 0, … means “for every ε, if ε > 0 then …”, and ∃ δ > 0, … means “there is a δ with δ > 0 and …”. A bound like ∀ x ∈ ℝ gives the variable its type.

Theorem: "Triangle inequality"
Claim: ∀ a ∈ ℝ, ∀ b ∈ ℝ, |a + b| ≤ |a| + |b|
Proof:
    Let a, b : ℝ
    Step: |a + b| ≤ |a| + |b|
QED

Expressions

  • Arithmetic + − * / ^, absolute value |x|, min, max.
  • Functions: sqrt exp ln log sin cos tan sinh cosh tanh asin acos atan floor ceil sign binomial.
  • gcd(a, b) and lcm(a, b) are computed for numbers (gcd(8, 6) = 2); for symbols they stay unevaluated, because gcd(n, k) has no closed form.
  • Constants: pi, e and oo (∞). Declaring one of these names makes it an ordinary variable again.
  • Congruence: a = b (mod m), a \equiv b \pmod{m} or Congruent(a, b, m).
  • Predicates: Even, Odd, MultipleOf(a, b), Divides(b, a), Positive, NonNegative.
Let n : ℕ
Assume n ≥ 1
Step: n! = n·(n − 1)!
Step: 5! = 120
Step: gcd(8, 6) = 2

Domain conditions

Dividing by B needs B ≠ 0, and √A needs A ≥ 0. If nothing in scope guarantees it, the step is marked with a domain warning — or refused outright with Strict domains switched on. Inside a sum, the condition only has to hold over the index's range.

Let x : Real
Step: (x^2 - 4) / (x - 2) = x + 2
Let x : Real
Assume h: x != 2
Step: (x^2 - 4) / (x - 2) = x + 2
