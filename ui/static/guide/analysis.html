Real analysis

Limits, infinity, sums and the ε–δ arguments that tie them together.

ε–δ arguments

Fix ε, construct δ, prove the inner implication in a Subproof, then conclude the existential with the δ you built as its witness.

Theorem: "lim 3x = 6 at x = 2"
Claim: ∀ ε > 0, ∃ δ > 0, ∀ x ∈ ℝ, |x − 2| < δ ⇒ |3·x − 6| < ε
Proof:
    Given ε : ℝ where ε > 0
    Let δ = ε / 3
    Subproof:
        Given x : ℝ
        Assume |x − 2| < δ
        Step: |3·x − 6| = 3·|x − 2|
        Step: < 3·δ
        Step: = ε
    Therefore ∃ δ > 0, ∀ x ∈ ℝ, |x − 2| < δ ⇒ |3·x − 6| < ε [witness: ε / 3]
QED

Limits

lim(f, x, a) or \lim_{x \to a} (f); add "+" or "-" for one side, and use oo or \infty for limits at infinity. A limit that does not exist is refused with the reason: the one-sided limits differ, the expression oscillates, or it tends to +∞ on one side and −∞ on the other.

Step: lim((9 - x^2)/(x + 1), x, 2) = 5/3
Step: lim(x/|x|, x, 0, "+") = 1
Step: lim(1/x, x, 0, "+") = oo
Step: \lim_{x \to \infty} (1 - 1/x^2) = 1
Step: lim((1 + 1/x)^x, x, oo) = e
Step: lim(x/|x|, x, 0) = 1

In the LaTeX form the limit takes one term, so wrap a sum in parentheses: without them, \lim_{x \to \infty} 1 - 1/x^2 is the limit of 1, minus 1/x^2.

Infinity

oo follows the notes' extended-real arithmetic: a + oo = oo, a / oo = 0 and -oo < a < oo hold for every real a, while the indeterminate forms oo − oo and 0 · oo are refused.

Series

When a closed form depends on a case — r = 1 or not, |r| < 1 or not — the hypotheses you have stated choose the case. With nothing in scope to decide it, the step is refused rather than guessed.

Let r : Real
Let n : Nat
Assume r != 1
Step: sum(k, 0, n, r^k) = (1 - r^(n + 1))/(1 - r)
Assume |r| < 1
Step: \sum_{k=0}^{\infty} r^k = 1/(1 - r)

Bounds with sin, cos and exp

The solver knows the true ranges of these functions — |sin x| ≤ 1, exp x > 0 and exp t ≥ 1 + t — which covers most inequalities in a first analysis course.
