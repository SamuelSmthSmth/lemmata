Keyboard

Everything in Aether can be reached from the keyboard. Ctrl is ⌘ on a Mac.

Anywhere

Ctrl KCommand palette: commands, files, and Library entries by reference (2.18)
Alt 1 … 4Proofs, Library, Guide, Settings
Alt NNew proof
Alt BShow or hide the reading pane

In the editor

Tab / Shift TabIndent / outdent by four spaces
EnterNew line; after a line ending in : it indents one more level
Ctrl SpaceCompletion: keywords, functions, your variables, proof templates
F8 / Shift F8Next / previous problem
Ctrl FFind and replace
Ctrl Z / Ctrl Shift ZUndo / redo

In lists

↑ ↓ Home EndMove between steps in the auditor, or rows in Files
← →Open and close folders; move between tabs
F2 / DeleteRename / delete the focused file (deleting can be undone)
Arrow keys on a panel gripMove that panel along the arrangement
